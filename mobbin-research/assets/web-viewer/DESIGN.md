# Research Sea DESIGN.md

## 设计意图

设计师打开查看器，是为了在一片图片之海里**被启发**，不是为了读报告。三个动作构成浏览体验：

- **扰动**：光标划过海面，附近的点微微变亮。
- **关联**：停在一张图上，像摄影机拉焦：相关的图按距离依次对上焦（头顶亮起白点），其余的图失焦、退后。
- **游览**：拖拽在海里移动，滚轮改变深度。入场时先浮在海面看全貌，然后自动下潜；点击一张图，镜头一路推到它占满画面。

结构只用位置表达：离中心越近，越是直接竞品；同一个模式大致占同一片方向；关系越近的图，彼此离得越近。界面上不写"直接竞品""间接竞品"这类字，也不画连线。设计师通过距离、疏密和岛屿的形状自己感受这些关系。

**克制原则**：空间是稳定的，截图从不被扭曲或推开；动效只在设计师停下来时才说话。拖拽、滚轮、运镜时，关联不会被唤醒；唤醒后的变化也只是对焦和失焦，不闪烁。

**善解人意**：界面跟随设计师当下的浏览状态柔软地响应，并比他快一步。缩放到接近最深、某张图已靠近画面中央时，界面判断他想看这张图，替他完成聚焦；他往回缩，界面就松开聚焦。聚焦时，与看图无关的信息（标题、HUD）退场，面板只在聚焦时出现。设计师不需要理解"海面""下潜"这类概念，缩放本身就是全部的交互。

视觉语言参考 [nullframe](https://github.com/m1ckc3s/nullframe)（Nothing 设计语言）：纯黑底、点阵结构、机器文字大写、动效"砸下去再稳住"、红色全页只出现一次。

## 海面

| 参数 | 值 | 说明 |
|---|---|---|
| 点阵间距 `G` | 26（世界单位） | 网点的密度 |
| 截图尺寸 | 36 × 78 | 手机截图比例 |
| 格点 | 列距 2G、行距 4G | 截图中心落在格点上，四周露出一圈点，行列始终对齐 |
| 涌动 | 一道从中心向外的慢涌，叠加一道斜向交叉波 | 点的亮度 ±6%、大小 ±22%；截图只起伏 1% |
| 尾迹 | 光标移动越快，附近的点越亮，最多 +12% | 扰动的反馈 |

### 两种布局（顶部开关切换，带 0.9 秒错落过渡）

- **岛屿 Island**：形状由数量决定。取包含 N 个格点的最小完整圆，多出的格子在最外圈按角度均匀去掉，得到一个对称的点阵圆。再按"圈层定半径、模式定方向"给每张图初始位置，在关系分数 ≥ 0.3 的图之间加弹簧（分数越高越短越硬），得到每张图的理想位置；最后用匈牙利算法求总位移最小的一一分配，把每张图填进格子。外形规整，直接竞品在中心，关系近的图彼此相邻。
- **航道 Lanes**：每个模式一条横向航道，左侧标模式名和数量；从左到右依次是深度 D01–D04，同一深度的列跨航道对齐。未走过的线索排在航道的尽头。

### 景深

被唤醒时，焦点和相关图保持清晰；其余的图在清晰版和失焦版之间交叉渐变，并缩小 4%。失焦版在图片加载时生成一次：48×104 的画布上做 4px 高斯模糊（不支持画布滤镜时退回 14×30 的缩小图），绘制时拉伸，几乎没有额外开销。截图从不被移动或放大；相关图按距离依次对焦，越远越晚，不画波纹。

## 动效

| 交互 | 时长与曲线 | 说明 |
|---|---|---|
| 入场 | 一道从中心荡开的波（1.6px/ms）：点阵依次亮起，截图按 back easing 弹入 | 回放调研的生长 |
| 自动下潜 | 入场波纹铺开后约 0.35 秒，用 1.3 秒的 ease-in-out（五次方）下潜到直接竞品的重心，每张图约占画面高度 18% | 缩放在对数空间插值，中心点沿直线移动；任何直接操作都会打断 |
| 回到全貌 | 1.2 秒，同一曲线 | 快捷键 `F`；界面上不设按钮，缩放即可 |
| 预判聚焦 | 停手 90ms 后，若缩放已达最深一档的 55% 以上，且有一张图的中心落在画面中央的容差内（横向 0.9 张图宽、纵向 0.7 张图高），或已达 85% 且光标正在某张图上，就用 0.48 秒吸附过去聚焦（快出缓停） | 在最深处拖拽后松手，同样吸附到离中心最近的图，像翻页 |
| 松开聚焦 | 聚焦时往回缩到最深一档的 72% 以下立即松开；停手后不在任何图上，也松开 | 面板滑走，标题和 HUD 回来 |
| 退出聚焦（Esc、关闭按钮、点击空白） | 以刚才那张图为中心，0.7 秒 ease-out 往后拉到最深一档的 40%（每张图约占画面高度 30%） | 视野重新打开，刚才的图仍在中央；停在预判聚焦的 60% 阈值之下，不会立刻被吸回去 |
| 拖拽 | 1:1 跟手，松手后按速度惯性滑行 | 速度按指数衰减 |
| 滚轮 | 向下滚动潜入，向上浮起；触控板捏合保持张开放大 | 以光标为中心，指数趋近 |
| 唤醒 | 光标放缓（< 0.6px/ms）并停留 140ms 触发（切换焦点 120ms）；拖拽、滚轮、滑行、运镜、布局切换期间及结束后 0.25 秒内不触发 | 失焦以 2.2px/ms 从焦点向外扩散，整屏约 0.3 秒到齐；单张图的对焦与失焦约 60ms 时间常数；离开 450ms 后平息 |
| 聚焦时的界面 | HUD 下移淡出；暗角和上下压暗带同时减弱 | 面板里已有同样的信息，图片边缘不被压暗 |
| 面板出现时 | 标题上移淡出；Insight、Replay 以 back easing 滑到屏幕左上角 | 不和面板挤在一起 |
| 悬停 | 离光标最近的图放大 4% | 唯一即时的反馈 |
| 点击 | 固定这张图，镜头用 0.85 秒推到最深一档（图片占画面高度约 75%），曲线为四次方 ease-out：起步立即响应，到位时轻轻落定 | 面板同时弹入，只放数据，不再重复大图 |
| 面板出现 | 卡片依次弹入：`translateY(22px) scale(.93)` → 原位，520ms back easing，间隔 55ms | 出场 200ms，比入场快 |
| 面板内容切换 | 旧内容 110ms 淡出并加 2px 模糊 | 随后新卡片依次弹入 |
| 卡片悬停 | 一道 1.05 秒的斜向光扫过 | 来自 nullframe |
| 深度计 | 面板打开时左移，420ms back easing | 模式索引改为淡出 |

开启 `prefers-reduced-motion` 时：关闭涌动、滑行和运镜，入场直接显示全部内容，只保留透明度变化。

## 时序与边界

### 时序

| 情况 | 处理 |
|---|---|
| 快速换焦点 | 已在景深状态时切换焦点，只在现有明暗上过渡，不重新扩散；只有从无焦点进入时才扩散。切换门槛高于首次触发（停留 200ms、光标 < 0.35px/ms），划过时不会频繁切换。实测远处失焦图的亮度在切换全程保持不变 |
| 聚焦的进出 | 迟滞区间：缩放达到最深一档的 60% 以上才可能预判聚焦，低于 45% 才松开，中间保持原状 |
| 面板与按钮的收起 | 松开后不立即收起：等到用户停手 260ms 以上、镜头和滑行都已静止，才收起面板、把按钮移回右上；在此之前若再次聚焦，只换面板内容。实测连续三轮快速推拉，面板和按钮零次变化 |
| 按钮移动 | 0.56 秒抽屉曲线，沉稳不弹跳 |

### 边界

| 情况 | 处理 |
|---|---|
| 模式很多 | 右下索引是一个没有边框的滚动区，固定 132px（约 6 行）高，按数量从多到少排列；下方还有内容时显示一个轻轻起伏的点阵向下箭头（点击下滚 3 行），滚到底时消失；滚动后顶部渐隐。高度固定，不会碰到深度计。名字超过 150px 省略。分段条按最大值等比缩放，最多 16 段。平时 72% 透明度，悬停时完全显示 |
| 文字很长 | 洞察、Agent 笔记、线索链、呼应说明、概览各列表、模式说明、缩略图网格都放进 `.clip`：各自设最大高度，超出部分在卡片内滚动；只有确实被截断的一侧才显示渐隐。卡片标题最多两行；左上标题、HUD 单行省略 |
| 关联很多 | 最多 8 张；按类型限额：线索类（LEAD、SIBLING）3、呼应类（ECHO、CONTRAST）3、同模式 4、同 App 2，名额没用满时再按分数补齐；同分时优先深度相近、来自不同 App 的图 |
| 截图很多 | 160 张实测流畅。布局的两两计算和匈牙利算法都是 O(n²)～O(n³)，几百张以内可接受 |
| 分享与定位 | 网址参数 `layout` 记录布局，`frame` 记录聚焦的帧；打开带 `frame` 的链接直接聚焦到该帧 |

## 组件

- **焦点图**：一圈 1px 白色细框；被固定时四角加白色角标。点击后镜头推到最深一档，图片占画面高度约 75%，此时改用原图绘制。
- **相关图**：头顶一粒白点。图足够大时（宽度超过 40px），下方显示关系标签：`LEAD`、`SIBLING`、`ECHO`、`CONTRAST`、`PATTERN`。
- **线索点**：海岸线外的橙色呼吸点表示 open 的线索，灰点表示 empty。悬停时 HUD 显示线索内容。
- **HUD**（左下）：光标下的帧号、Distance 分段条、关联数，以及"App — 屏幕类型 · 模式"。空闲时显示键位指引式的操作提示：点阵图标加一个词——四向箭头 Drift（拖拽）、滚轮鼠标 Dive（滚动）、沙漏 Relate（停留）、左键鼠标 Focus（点击）。
- **模式索引**（右下）：每个模式一行，名称加分段条。悬停预览这个模式的成员，点击打开模式面板；模式多时在原位滚动（见"边界"）。
- **深度计**（右侧中部）：14 格刻度，越深亮得越多。
- **工具栏**（右上；面板出现时移到左上）：Insight、Replay。
- **点阵字形**：所有图标都由 2px 圆点按行绘制（`viewer/glyph.js` 的 `GLYPHS`，以 `|` 分行），宽度不限，与开关、分段条同一语言。
- **暗角与压暗带**：常驻的径向暗角（75%）加顶部 150px、底部 210px 的线性压暗带，保证真实截图上的文字可读；聚焦时减弱。
- **标题**（左上）：调研主题加一行元信息（图片数 · 模式数 · 日期），面板出现时让位。
- **布局开关**（顶部中间）：Island / Lanes 分段按钮，选择会写入网址参数，便于分享当前视图。
- **面板**：一列 bento 卡片，只展示数据，看图交给画布。单张图依次是：
  1. 标题卡：红点（聚焦中）与帧号、App、屏幕类型、模式标签（可点开模式面板）
  2. Distance：4 段分段条与 `0N / 04`，表示离直接竞品有多远（对应圈层 R1–R4）
  3. Insight：Agent 总结的启发，下方是保存时的 Agent 笔记与轮次
  4. Trail：从调研起点到这张图的线索链，每一步可点击跳转
  5. Related：关联图（标题行右侧是点阵数字的数量）与关系标签，下方是呼应 / 对照说明
  6. Open in Mobbin

  另有框选、模式、概览三种状态。"Distance"（圈层远近）与右侧深度计的"Depth"（缩放深浅）是两个不同的概念，命名上刻意区分。
- **说明图标**：Distance、Trail、Related 标题旁一个 14px 细描边圆，内含机器字体的小写 i。悬停或键盘聚焦 120ms 后在下方显示说明（`#tip`，最宽 260px）；刚关闭 0.6 秒内移到相邻图标会立即显示。面板滚动或换内容时提示自动收起。说明文案在 `viewer/cards.js` 的 `TIPS` 中，是结构化的：一句加粗的总述，加一张对照表（左列机器字体的标签，如 `01`、`LEAD`）或一个短列表，必要时以细线隔开一句补充。
- **结构化笔记**：Agent 笔记、检查点小结、模式三段与缺口中，以 `- ` 开头的行排成列表（3px 圆点），`标签：内容` 的标签以 500 字重高亮；没有要点的文字按普通段落显示。排版习惯见 `references/data-contract.md` 的"笔记的排版习惯"；内容和标签由 Agent 自己决定。

## 健壮性

- 帧循环在每帧开头先调度下一帧，单帧出错只影响这一帧，画布不会整体停住。
- 曾出现的问题：光标靠近海岸线外的线索点时，HUD 取值多了一层导致报错，帧循环中断、画布冻住（面板是 DOM，仍能弹出）。已修复。

## 待定项

- 真实 Mobbin 截图的亮度差异很大，纯黑底上浅色截图的刺眼程度需要用一次真实调研来验证。
- 屏幕超过约 300 张时，点阵每帧的计算量和布局的两两计算（O(n²)）需要重新评估。

# Research Sea DESIGN.md

## 设计意图

设计师打开查看器，是为了在一片图片之海里**被启发**，不是为了读报告。三个动作构成浏览体验：

- **扰动**：光标划过海面，附近的点微微变亮。
- **关联**：停在一张图上，像摄影机拉焦：相关的图按距离依次对上焦（头顶亮起白点），其余的图失焦、退后。
- **游览**：拖拽在海里移动，滚轮改变深度。入场时先浮在海面看全貌，然后自动下潜；点击一张图，镜头一路推到它占满画面。

结构只用位置表达：离中心越近，越是直接竞品；同一个模式大致占同一片方向；关系越近的图，彼此离得越近。界面上不写"直接竞品""间接竞品"这类字，也不画连线。设计师通过距离、疏密和岛屿的形状自己感受这些关系。

**克制原则**：空间是稳定的，截图从不被扭曲或推开；动效只在设计师停下来时才说话。拖拽、滚轮、运镜时，关联不会被唤醒；唤醒后的变化也只是对焦和失焦，不闪烁。

视觉语言参考 [nullframe](https://github.com/m1ckc3s/nullframe)（Nothing 设计语言）：纯黑底、点阵结构、机器文字大写、动效"砸下去再稳住"、红色全页只出现一次。

## 海面

| 参数 | 值 | 说明 |
|---|---|---|
| 点阵间距 `G` | 26（世界单位） | 网点的密度 |
| 截图尺寸 | 36 × 78 | 手机截图比例 |
| 格点 | 列距 2G、行距 4G | 截图中心落在格点上，四周露出一圈点，行列始终对齐 |
| 涌动 | 一道从中心向外的慢涌，叠加一道斜向交叉波 | 点的亮度 ±6%、大小 ±22%；截图只起伏 1% |
| 尾迹 | 光标移动越快，附近的点越亮，最多 +12% | 扰动的反馈 |

### 两种布局（顶部开关切换，带 0.9 秒错落过渡）

- **岛屿 Island**：形状由数量决定。取包含 N 个格点的最小完整圆，多出的格子在最外圈按角度均匀去掉，得到一个对称的点阵圆。再按"圈层定半径、模式定方向"给每张图初始位置，在关系分数 ≥ 0.3 的图之间加弹簧（分数越高越短越硬），得到每张图的理想位置；最后用匈牙利算法求总位移最小的一一分配，把每张图填进格子。外形规整，直接竞品在中心，关系近的图彼此相邻。
- **航道 Lanes**：每个模式一条横向航道，左侧标模式名和数量；从左到右依次是深度 D01–D04，同一深度的列跨航道对齐。未走过的线索排在航道的尽头。

### 景深

被唤醒时，焦点和相关图保持清晰；其余的图在清晰版和失焦版之间交叉渐变，并缩小 4%。失焦版在图片加载时生成一次：48×104 的画布上做 4px 高斯模糊（不支持画布滤镜时退回 14×30 的缩小图），绘制时拉伸，几乎没有额外开销。截图从不被移动或放大；相关图按距离依次对焦，越远越晚，不画波纹。

## 动效

| 交互 | 时长与曲线 | 说明 |
|---|---|---|
| 入场 | 一道从中心荡开的波：点阵依次亮起，截图按 back easing 弹入 | 回放调研的生长 |
| 自动下潜 | 入场后约 1 秒，用 1.8 秒的 ease-in-out（五次方）下潜到直接竞品的重心，每张图约占画面高度 18% | 缩放在对数空间插值，中心点沿直线移动；任何直接操作都会打断 |
| 浮上海面 | 1.2 秒，同一曲线 | `F` 键或右上角按钮 |
| 拖拽 | 1:1 跟手，松手后按速度惯性滑行 | 速度按指数衰减 |
| 滚轮 | 向下滚动潜入，向上浮起；触控板捏合保持张开放大 | 以光标为中心，指数趋近 |
| 唤醒 | 光标基本静止并停留 380ms 触发（切换焦点 300ms）；拖拽、滚轮、滑行、运镜、布局切换期间及结束后 0.5 秒内不触发 | 离开 450ms 后平息；明暗变化按 0.2 秒的指数趋近 |
| 悬停 | 离光标最近的图放大 4% | 唯一即时的反馈 |
| 点击 | 固定这张图，镜头推到最深一档（图片占画面高度约 75%） | 面板同时弹入，只放数据，不再重复大图 |
| 面板出现 | 卡片依次弹入：`translateY(22px) scale(.93)` → 原位，520ms back easing，间隔 55ms | 出场 200ms，比入场快 |
| 面板内容切换 | 旧内容 110ms 淡出并加 2px 模糊 | 随后新卡片依次弹入 |
| 卡片悬停 | 一道 1.05 秒的斜向光扫过 | 来自 nullframe |
| 工具栏、深度计 | 面板打开时整体左移，420ms back easing | 模式索引改为淡出 |

开启 `prefers-reduced-motion` 时：关闭涌动、滑行和运镜，入场直接显示全部内容，只保留透明度变化。

## 组件

- **焦点图**：一圈 1px 白色细框；被固定时四角加白色角标。点击后镜头用 1.3 秒推到最深一档，图片占画面高度约 75%，此时改用原图绘制；暗角随之退开。
- **相关图**：头顶一粒白点。图足够大时（宽度超过 40px），下方显示关系标签：`LEAD`、`SIBLING`、`ECHO`、`CONTRAST`、`PATTERN`。
- **线索点**：海岸线外的橙色呼吸点表示 open 的线索，灰点表示 empty。悬停时 HUD 显示线索内容。
- **HUD**（左下）：光标下的帧号、深度分段条、关联数，以及"App — 屏幕类型 · 模式"。空闲时显示操作提示。
- **模式索引**（右下）：每个模式一行，名称加分段条（一段一张图）。悬停预览这个模式的成员，点击打开模式面板。
- **深度计**（右侧中部）：14 格刻度，越深亮得越多。
- **工具栏**（右上）：Insight、Replay、Dive / Surface，图标由 5×5 点阵字形构成。
- **布局开关**（顶部中间）：Island / Lanes 分段按钮，选择会写入网址参数，便于分享当前视图。
- **面板**：一列 bento 卡片，只展示数据，看图交给画布。单张图：帧号与标题、模式、深度与关联数、洞察与 Agent 笔记、线索链、相关图、Mobbin 链接。另有框选、模式、概览三种状态。

## 待定项

- 真实 Mobbin 截图的亮度差异很大，纯黑底上浅色截图的刺眼程度需要用一次真实调研来验证。
- 屏幕超过约 300 张时，点阵每帧的计算量和布局的两两计算（O(n²)）需要重新评估。

# 调研网查看器 DESIGN.md

## 设计意图

设计师打开查看器，是为了**被一组图启发**，不是为了读报告。所以：

- **图是唯一的颜色来源。** 界面本身只用暖中性色，所有色彩都来自截图。
- **结构靠位置表达，不靠装饰。** 同心圆的半径表示圈层（中心是直接竞品），扇区表示设计模式。节点上没有色条或标签。
- **浏览本身就是探索。** 悬停一张图，和它关系最近的几张会聚拢成一个簇；悬停簇中的另一张，网会围绕它重新聚拢。设计师可以像走路一样，沿着关系在网中漫游。
- **Agent 的声音用衬线体。** 洞察、笔记、检查点这些 Agent 写下的话用 `--font-voice`，界面文字用 `--font-ui`。设计师一眼就能分清"这是 Agent 的判断"和"这是界面"。

## 动效

| 交互 | 时长与曲线 | 说明 |
|---|---|---|
| 节点位移、缩放 | 弹簧（刚度 210，阻尼 26） | 可被打断：簇团切换时节点从当前速度继续运动，不会跳回起点 |
| 悬停即时抬起 | 弹簧，scale 1.1 | 指针一碰到就有反馈 |
| 进入簇团 | 停留 90ms 后触发；切换焦点需停留 220ms | 防止指针划过时整张网来回跳动 |
| 退出簇团 | 离开 260ms 后恢复 | 给指针在簇内移动留出余量 |
| 簇团外的扰动 | 焦点附近的节点被轻轻推开，并淡到 0.16 | 制造涟漪感，让焦点自然浮现 |
| 静止时的呼吸 | 每个节点 ±1.6 世界单位，周期 7–11 秒 | 网是"活的"；减少动态效果时关闭 |
| 入场 | 按保存顺序，每张间隔 14ms，从父节点位置长出 | 回放调研时网的生长过程 |
| 面板出现 | 340ms `--ease-drawer`，从右侧 20px、scale .985 进入 | 出场 200ms `--ease-out`，比入场快 |
| 面板内容切换 | 旧内容 110ms 淡出并加 2px 模糊，新内容按 24ms 间隔依次入场 | 模糊让两种状态融成一次变化 |
| 镜头飞行 | 指数趋近，约 400ms 稳定 | 只用于程序触发的移动；拖拽、缩放 1:1 跟手 |

曲线：`--ease-out: cubic-bezier(.23, 1, .32, 1)`，`--ease-drawer: cubic-bezier(.32, .72, 0, 1)`。

开启 `prefers-reduced-motion` 时，节点直接到位，只保留透明度变化。

## 组件

- **节点**：截图缩略图，圆角 16px（基准尺寸 240×520，按镜头缩放），1px 内描边 `--line`。焦点节点带投影，并在下方显示 App 名和屏幕类型。
- **连线**：线索关系用 `--ink` 实线；呼应和对照用 `--clay` 实线；共享模式用 `--ink-2` 虚线。平时只以很低的透明度显示线索网；聚焦时，焦点到簇内成员的连线依次画出。
- **扇区标签**：模式名称加数量，位于最外圈之外。悬停时预览该模式的成员，点击打开模式面板。
- **面板**：右侧浮层，宽 380px，上下各留 16px。根据选中内容切换五种状态：概览、单张图、多选、模式、空。
- **工具栏**：右上角，包括"洞察"（打开概览）、重播入场、适配视图三个按钮。左下角是快捷操作提示，首次交互后淡出；右下角是缩放控制。

## 待定项

- 截图本身很亮或很暗时，暖纸色画布能否同时衬托两类截图，需要用真实 Mobbin 截图验证。
- 演示数据使用的是 Unsplash 抽象渐变图，不代表真实截图的视觉密度。
